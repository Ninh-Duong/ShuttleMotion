# Frontend

Plain HTML, CSS, and JavaScript for the responsive bilingual court viewer and local logs page. The 2D SVG and Three.js scene consume the same `../docs/reference/badminton/court.json` geometry. The homepage also hosts the shuttle vector sandbox. `shot.html` / `shot-app.mjs` is the shot lab teaching page at `/shot`. Flight physics, aiming and the player reach geometry live in `shuttle-physics.mjs`, which is pure and unit-tested in Node. See `../docs/FEATURE_SHUTTLE_SANDBOX_PLAN.md`. `training.html` / `training-app.mjs` is the doubles training page at `/training`. It fetches lessons from the backend API and animates them with `lesson-timeline.mjs` (see `../docs/FEATURE_DOUBLES_TRAINING_PLAN.md`). `ui.mjs` holds what the three pages share: the remembered UI language, common Vietnamese/English words, number formatting, JSON fetching and on-demand loading of the 3D court. See `../docs/ARCHITECTURE.md` for the selected stack and boundaries.
